Settings

GitHub Data Storage

All data is read from and written to data/data.json in the GitHub repository using the GitHub API. Saving changes needs a Personal Access Token with write access to the repo.

Create a token here (select "repo" scope, set expiry as needed).

Transfer Token to Another Device

Copy the token to your phone or another browser without retyping it. Save the token above first, then open the link or scan the QR code on the other device. It opens the login page with the token loaded.

Note: the link contains the token. Only share it with your own devices and avoid sending it through chat or email. The token stays in the URL after # (it is never sent to a server), and the app removes it from the address bar as soon as it loads. A read-only device needs no write token: if the repo is public, don't transfer a token there at all; if it is private, use a fine-grained token with read-only "Contents" permission.

Scan this QR code with the phone's camera, then open the link. The token loads automatically.
